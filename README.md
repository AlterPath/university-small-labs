# Небольшие учебные работы

[English version](README.en.md)

Мелкие лабораторные и практики 2024–2025 годов в одном месте.

## Моделирование роботов (`robot-modeling/`, октябрь 2025)

Двухзвенный манипулятор со звеньями по 30 см проходит П-образную траекторию со скоростью 5 см/с:
- точки траектории по секундам;
- обратная кинематика с двумя решениями (локоть вверх и вниз) и проверка достижимости точки;
- результат в CSV и интерактивные графики углов (`P_trajectory_plots.html`).

## Методы искусственного интеллекта (`ai-methods/`, февраль–март 2025)

- `game_of_life_fsm.ipynb`: «Игра жизнь» на сетке 250 × 250. Каждая клетка устроена как конечный автомат, анимация в Matplotlib.
- `finite_automaton/`: конечный автомат поведения агента. Состояния заданы по показаниям датчиков (стена, враг и цель с разных сторон) в `automaton.json`, рядом схема автомата.
- `log_regex.ipynb`: разбор строк журнала сервера регулярными выражениями. Сам журнал в репозиторий не входит.

## Базы данных (`databases/`)

- `design/` (май–июнь 2024): проектирование информационной системы компании, которая собирает ракеты на заказ.
  - Диаграммы вариантов использования, классов, последовательности и деятельности.
  - ER-диаграмма в нотации Чена.
  - Исходники в drawio и картинки в PNG.
- `sql/` (октябрь 2025): схема MySQL для сервиса аренды жилья (пользователи, объявления, бронирования, отзывы) и запрос бронирований за выбранную неделю.

## Стек

Python, NumPy, pandas, Matplotlib, Plotly, MySQL, draw.io, Visual Paradigm.
